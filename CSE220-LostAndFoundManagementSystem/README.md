# Lost and Found Management System

## Project Overview

The Lost and Found Management System is a proposed software system designed to help users report, search, and recover lost and found items.

The project follows an Agile software development approach using Trello for project management and GitHub for documentation and version control.

## Project Objectives

- Allow users to report lost items.
- Allow users to report found items.
- Allow users to search and filter reported items.
- Allow users to submit claims for found items.
- Allow staff to verify ownership.
- Provide notifications regarding reports and claims.
- Allow administrators to manage records and generate reports.

## Repository Structure

### requirements/
Contains functional requirements, non-functional requirements, and stakeholder analysis.

### design/
Contains the Use Case, Class, Sequence, and Activity Diagrams.

### testing/
Contains the detailed test case matrix in Excel format.

### project-management/
Contains project backlog, sprint planning, and Gantt chart documents.

### documentation/
Contains project documentation and version control information.

## Agile Process

The project is organized into two sprints:

Sprint 1 focuses on core functionality such as login, reporting lost and found items, searching, filtering, and viewing item details.

Sprint 2 focuses on claims, ownership verification, notifications, administrative functions, and reporting.

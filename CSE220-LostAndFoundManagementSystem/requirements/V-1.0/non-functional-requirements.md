## Non-Functional Requirements

| ID | Requirement | Category |
|---|---|---|
| NFR-01 | The system shall respond to normal search requests in an acceptable manner within an acceptable time. | Performance |
| NFR-02 | The system shall offer an intuitive user interface for reporting, searching, and claiming items with minimal effort. | Usability |
| NFR-03 | The user shall be required to log on to protected account functions. | Security |
| NFR-04 | The system shall ensure that claim verification or administrative tasks are carried out by authorized personnel and/or administrators only. | Security |
| NFR-05 | The system shall ensure that user information and ownership evidence are protected from unauthorized access. | Security |
| NFR-06 | The system shall maintain accurate and consistent records of lost items, found items, and claims. | Reliability |
| NFR-07 | The system will operate during normal service periods with only minor service interruption. | Availability |
| NFR-08 | The system should support a growing number of users, item reports, and claims without a drastic loss of performance. | Scalability |
| NFR-09 | The system shall provide clear error messages when invalid or incomplete information is submitted. | Usability |
| NFR-10 | The system should allow tracking of important item and claim changes. | Maintainability / Auditability |

## Stakeholders

The current project report does not contain a separate detailed stakeholder-analysis table. The following entries are derived only from stakeholder roles and needs already stated in the report.

| Stakeholder | Main Interest / Need | Related System Functions |
|---|---|---|
| General User | A centralized way to report, search, claim, and track lost/found items | Register/login, report lost item, report found item, search/filter, submit claim, notifications, status tracking |
| Administrator | Control and verification of records and claims | Validate claims, approve/reject claims, update item status, monitor records, generate reports |
| Lost & Found Staff / Authorized Personnel | Reliable ownership verification and organized item handling | Verify ownership, review claims, manage status, support item recovery |
| Organization / Institution | Better record keeping and a centralized process for lost and found activities | Central records, monitoring, reporting, controlled access |
| Project Team | Complete the simulated Agile project with traceable artifacts | Backlog, requirements, UML, testing, Trello, GitHub, version control |
| Instructor | Review project evidence and approve submitted academic artifacts | Documentation review, version-control evidence, final submission |

# Requirements V-1.1

This folder is reserved for the first minor revision of requirements artifacts.

When a V-1.0 requirement document changes:

1. Copy the affected file from `requirements/V-1.0/` into this folder.
2. Update `Version` from `1.0` to `1.1`.
3. Update `Last Updated`, `Status`, and `Change Description`.
4. Update `project-management/version-control-document.md`.
5. Commit the change from a student's branch and merge it through a Pull Request.
